# Security Policy

## Supported versions

Security updates are provided only for the latest published release of `logcut`.
Older releases are not supported. Please upgrade to the latest release before
reporting a vulnerability.

| Version | Supported |
| --- | --- |
| Latest published release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, pull request, or
discussion.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/YamabikoLab/logcut/security/advisories/new).

Please include, when possible:

- the affected `logcut` version and environment;
- a description of the vulnerability and its potential impact;
- steps to reproduce or a minimal proof of concept;
- any suggested mitigation.

Do not include real credentials, tokens, personal information, or other secrets
in the report.

## Response process

The maintainers will:

1. confirm receipt and triage the report;
2. investigate the issue and assess its impact;
3. prepare and validate a fix when necessary;
4. coordinate disclosure with the reporter;
5. publish a security advisory and updated release when appropriate.

No specific response or resolution time is guaranteed, but the reporter will be
kept informed as the investigation progresses. Reporter credit will be included
when requested and appropriate.
