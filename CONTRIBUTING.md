# Contributing

Thank you for your interest in `logcut`.

## Issues

GitHub Issues are used for bug reports and feature requests.
General usage questions and support requests are not accepted as Issues.

Before opening an Issue, please confirm that the problem applies to:

- the latest published release of `logcut`;
- an environment listed as supported in the README; and
- currently documented CLI options, settings, or profiles.

Windows and macOS are outside the documented support scope.

### Bug reports

When reporting a bug, please include as much of the following information as possible:

- the `logcut` version;
- Linux distribution and architecture;
- the command that was run;
- steps to reproduce the problem;
- the expected result;
- the actual result; and
- relevant errors or logs.

Do not include passwords, tokens, credentials, personal information, or other secrets in logs or reports.

### Feature requests

Feature requests are welcome as Issues. Please describe the use case and the behavior you would like to see.

## Pull requests

External Pull Requests are not accepted.
Development and repository changes are handled by the maintainer. Proposed changes should be submitted as feature requests through Issues instead.

## Security issues

Do not report suspected security vulnerabilities in public Issues or Pull Requests.
Follow [SECURITY.md](SECURITY.md) and report vulnerabilities privately through GitHub Security Advisories.
